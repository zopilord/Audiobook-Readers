# First public release

Packages prepared for this release:

- `audiobook-workflow-linux.zip`
- `audiobook-workflow-windows.zip`
- `audiobook-reader-linux.zip`
- `audiobook-reader-windows.zip`
- `audio-web-reader-linux.zip`
- `audio-web-reader-windows.zip`

The Web Reader archives were sanitized before publication so the documentation uses `HOST_TAILSCALE_IP` instead of a personal Tailscale address.

Android and Kindle documentation are included in the repository, but their release packages were not included in this upload set.
